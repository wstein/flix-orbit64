# Code of conduct

This project welcomes respectful technical discussion in issues, pull
requests, reviews, and other spaces managed by the project.

Be considerate of other participants. Critique ideas and code without personal
attacks. Harassment, threats, discriminatory remarks, and publishing another
person's private information are not acceptable.

Maintainers may remove comments, lock discussions, or restrict participation
when conduct disrupts the project or puts people at risk. They will consider
the context and severity of each incident.

To report abusive content privately, use GitHub's **Report abuse** action on
the relevant content. For a project-specific concern that can be discussed
publicly, open an issue; do not include private or sensitive information in it.
