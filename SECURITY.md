# Security policy

Security reports are assessed for the latest tagged release and the current
`main` branch. Older releases do not have a standing backport commitment.
Include the affected version or commit when reporting a problem.

Private vulnerability reporting is not currently enabled for this repository.
If you believe you found a vulnerability, open an issue titled **Security
contact requested** without including exploit details, credentials, or other
sensitive information. A maintainer can then arrange a private reporting
channel. Use the bug report issue form for problems that can safely be
discussed in public.
